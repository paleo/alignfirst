# alignfirst-dev-kit-tests

Local Dockerised regression harness for the `myassistant` reference workspace. It is a standalone consumer of the `@alignfirst/openclaw-*` packages and is not part of the root npm workspaces.

- [Running the OpenClaw Tests](../docs/alignfirst-dev-kit/running-openclaw-tests.md) — setup, credentials, scenarios, fixtures, artifacts, and maintenance notes.
- [OpenClaw Test Harness Architecture](../docs/alignfirst-dev-kit/openclaw-test-architecture.md) — topology and internals.
- [`@alignfirst/openclaw-test` README](../packages/openclaw-test/README.md) — generic harness commands and APIs.
