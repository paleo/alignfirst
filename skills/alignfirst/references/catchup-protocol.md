# How to Catch Up With a Task

## Pre-requisites

You need the TASK_DIR — if you don't have it, use your instructions for finding the **ticket ID**, or ask the user.

## Steps

1. Determine TASK_DIR.
2. Read every `*request.md`, `*spec.md` and `*summary.md` file in TASK_DIR, in filename order.
3. When the user's message carries instructions, follow them with this context loaded, and write no synthesis. Otherwise reply with a short synthesis: what was requested, what was decided, what was done, what remains or is open.

This protocol writes no file.
