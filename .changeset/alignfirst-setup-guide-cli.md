Added the `setup` commands, which replace the `alignfirst-setup-guide` skill: `setup` reports the project state and prints the setup guide, `setup guide <topic>` prints a topic, `setup init` adopts the protocols, and `setup instructions` checks or writes the bootstrap section. Added an `Instructions` check to `doctor`, a setup pointer to `context`, and `--default-location` and a repeatable `--item <name>=<location>` to `companion register`.
