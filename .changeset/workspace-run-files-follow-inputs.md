A start no longer re-patches the run files on every run. It rewrites them only when the ports or the new `runFilesInputs` changed since the last write, and prints a warning, so a hand edit survives a restart. An explicit `dev setup` still rewrites them all. A run file generated by a `content` source without `patch` is now regenerated when the run files are rewritten.
